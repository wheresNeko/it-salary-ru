### Cyrillic С / Latin C trap

Russian adverts often write `C++` with a **Cyrillic** С (U+0421),
which looks identical. `re.IGNORECASE` does not fold across alphabets,
so a naive pattern silently misses them.

- vacancies matching only the **Latin** spelling: 137
- vacancies matching only the **Cyrillic** spelling: 102
- false-negative rate of a naive pattern: **102/239 (43%)**

## Sampling caveat

Within a single query the API returns its own ordering, which is
recency-weighted but is **not random and not explicitly sorted**. Each
(keyword, region) cell is capped at 100 records because the API's
paging is unreliable. The result is a **convenience sample**, not a
probability sample. Any inference drawn from it must say so.
